Project Task Checklists

Reusable step-by-step checklists for Project tasks, with progress tracking and automatic dates

Define a recurring routine once, such as client onboarding, a website launch or employee offboarding, as a checklist template. Apply it to any Project task in one click. Each task gets its own editable copy of the steps. Team members move each step through To Do, In Progress, Done or Cancelled, and the task shows a live progress bar. The task's checklist Start Date and End Date fill themselves in as work begins and finishes.

Key Features

Templates & tasks

  • Checklist templates under Project > Configuration > Checklists (project.checklist.template) with drag-reorderable steps and notes
  • Checklist field on the task form (next to Tags) copies the template steps into the task
  • Per-task steps (project.task.checklist.line) can be edited, reordered, added or removed. Template edits never change existing tasks.
  • Replace Checklist confirmation dialog once work has started, showing exactly how many done / in-progress / cancelled steps will be lost

Progress & dates

  • Start, Done, Cancel buttons per step with colour-coded, hand-editable status and row colours
  • Progress = done / (all − cancelled) × 100. For example, 5 steps, 2 done and 1 cancelled gives 2 / 4 = 50%.
  • Start Date / End Date auto-stamped from checklist activity. End Date clears itself when progress drops below 100%.
  • Checklist Progress column in the task list, With Checklist filter and search by Checklist

How it works

A Project Administrator creates a template in Project > Configuration > Checklists, e.g. "New Client Onboarding" with five steps. On a task, any user picks that template in the Checklist field. The steps appear on the task's Checklist tab as To Do. Clicking Start on the first step stamps today as the Start Date. When every non-cancelled step is Done, the progress bar reaches 100% and the End Date is stamped. Checklist steps follow the task's own visibility: users see the steps of tasks they can access, within their allowed companies.
