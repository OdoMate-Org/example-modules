Reusable checklist templates for Odoo Project. A Project Administrator defines
a routine once (e.g. "New Client Onboarding") under Project > Configuration >
Checklists. Any task can then pick it in its **Checklist** field, and the steps
are copied into the task as an independent, editable copy. Each step has
Start / Done / Cancel buttons and a colour-coded status. The task shows a
checklist progress bar, cancelled steps are left out of the calculation, and
the task's checklist Start Date and End Date are stamped automatically.

Installation
============

To install this module, you need to:

#. Clone or download the module into your Odoo addons path.
#. Update the apps list (Apps > Update Apps List).
#. Search for "Project Task Checklists" and click Install.

The only dependency is the standard ``project`` module.

Configuration
=============

After installation:

#. Go to Project > Configuration > Checklists (Project Administrator).
#. Create a template: give it a name, an optional description and add steps
   (name + optional note) on the **Steps** tab. Drag the handle to reorder.
#. Check that the **Steps Count** column in the Checklists list shows the
   expected number of steps.

Usage
=====

#. Open a task and select a template in the **Checklist** field (next to Tags).
   The steps are copied into the task and a **Checklist** tab appears.
#. Work through the steps with the **Start**, **Done** and **Cancel** buttons.
#. Progress = done / (all - cancelled) x 100. For example, 5 steps with 2 done
   and 1 cancelled gives 2 / 4 = 50%.
#. **Start Date** is set when the first step is started or done. **End Date**
   is set when progress reaches 100% and cleared again if it drops below 100%.
   Both stay editable by hand.
#. Once work has started, the Checklist field locks. To switch templates, use
   the **Replace Checklist** button, which opens a confirmation dialog.
#. In the task list, use the **Checklist Progress** column and the
   **With Checklist** filter.

For the full step-by-step guide, see ``doc/USER_GUIDE.md`` (also available in
Ukrainian: ``doc/USER_GUIDE.uk.md``, and Polish: ``doc/USER_GUIDE.pl.md``).

Known limitations
=================

* No emails, activities or reminders are sent on step status changes.
* Steps have no individual assignee or due date.
* No dedicated reports or dashboards; use the progress column and filters.
* Templates are global (not company-specific).
* Once any step is started, done or cancelled, switching templates requires the
  Replace Checklist button, not the dropdown. Replacing deletes the current
  steps.
* Done / Cancelled steps have no reopen button; change the Status cell by hand.

See ``doc/USER_GUIDE.md`` section "Limitations" for the full list.
