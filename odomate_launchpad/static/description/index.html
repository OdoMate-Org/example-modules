Launchpad

A personal app launcher that ranks your Odoo apps by pins and recent usage

Launchpad opens a full-screen grid of square tiles, one for every app you can access. Your pinned apps come first, followed by the apps you opened most in the last 30 days, then everything else alphabetically. Each user gets their own private order, with instant search and an optional one-click startup screen.

Key Features

Smart ordering

  • Tiles for every root app you can access (the same list as the standard app switcher)
  • Pinned apps first, in the order you pinned them
  • Then apps ranked by opens in the last 30 days, calculated live on each load (no stored counter, no cron)
  • Ties and unused apps sorted alphabetically

Fast, private, personal

  • Thumb-tack button to pin or unpin per user (odomate.launchpad.pin)
  • Instant search: Enter opens the first match, Escape clears
  • Set as Startup Screen sets only your own Home Action, and one more click reverts it
  • Usage log (odomate.launchpad.usage) visible only to its owner, with cascade delete when a user or app is removed

How it works

After installation, every internal user sees a new top-level Launchpad app (URL /odoo/launchpad). Clicking a tile logs one usage row and opens the app exactly like the standard menu. Over time your most-used apps move to the front. Pin the apps you always need to keep them at the top. For example, with Projects and Timesheets pinned, Employees opened 5 times, Discuss 4 times and Expenses 3 times, the order is Projects, Timesheets, Employees, Discuss, Expenses, and then the remaining apps alphabetically. No configuration, security groups or scheduled jobs are required.
