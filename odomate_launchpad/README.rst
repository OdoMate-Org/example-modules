Launchpad
==========================================

Launchpad is a personal, full-screen app launcher for Odoo. It shows a square
tile for every app the user can access, with the user's pinned apps first,
then the apps they opened most in the last 30 days, then the rest
alphabetically. It also has instant search (Enter opens the first match,
Escape clears) and a one-click button that makes the Launchpad the user's own
startup screen. Usage and pins are private to each user.

Installation
============

To install this module, you need to:

#. Clone or download the module into your Odoo addons path.
#. Update the apps list (Apps → Update Apps List).
#. Search for "Launchpad" and click Install.

Configuration
=============

No configuration is required. After installation, every internal user sees
a new top-level **Launchpad** app (URL ``/odoo/launchpad``). There are no
settings, security groups or scheduled jobs.

Usage
=====

#. Open **Launchpad** from the main menu.
#. Click a tile to open that app. Each click is logged and improves the
   ranking.
#. Click the thumb-tack on a tile to pin it to the top (for you only).
   Click it again to unpin.
#. Type in **Search apps...** to filter tiles. Press **Enter** to open the
   first match or **Escape** to clear.
#. Click **Set as Startup Screen** to open the Launchpad after every login.
   Click **Startup Screen** to revert.

Ordering: pinned apps (in pin order), then opens in the last 30 days
(descending, computed live on every load), then alphabetical.

For the full step-by-step guide, see ``doc/USER_GUIDE.md``
(Ukrainian: ``doc/USER_GUIDE.uk.md``).

Known limitations
=================

* Ranking is per user only. There is no shared or company-wide ordering.
* The usage log is never purged automatically. Rows older than 30 days are
  ignored but kept.
* Only opens from Launchpad tiles are counted.
* Tile icons depend on each app's web icon. Apps without one show their
  first letter.
* The standard Odoo app switcher is not reordered.
* Pins keep the order in which they were created. There is no drag-and-drop
  reordering.

See ``doc/USER_GUIDE.md`` section "Limitations" for the full list.
