Apps Dashboard

Apps Dashboard adds a personal **My Apps** home screen for internal users. It
shows a square tile (icon + name) for every top-level app the user can already
open from the native Odoo app menu, lets each user pin favorite apps with a
star so they appear first, filters tiles with a search box, and lets each user
choose the dashboard as their home screen after login. It adds no new models,
no new security groups and never grants additional access.

Installation
============

To install this module, you need to:

#. Clone or download the module into your Odoo addons path.
#. Update the apps list (Apps → Update Apps List).
#. Search for "Apps Dashboard" and click Install.

The module depends only on ``base`` and ``web``.

Configuration
=============

No configuration is required. Optionally, each user can make the dashboard
their home screen:

#. Open the avatar menu (top right) → **My Preferences**.
#. Set **Home Screen** to **Apps Dashboard** and click **Save**.
#. Log in again or reload the page; Odoo now opens on **My Apps**.

Choosing **Default Menu** clears the Home Action only if it currently points
to the dashboard; a different Home Action set by an administrator is kept.

Usage
=====

#. Click **My Apps** in the main app menu (or open ``/odoo/my-apps``).
#. Click a tile to open that app, exactly like the native app menu.
#. Click the star in a tile's corner to add it to **Favorites** (shown above
   **All Apps**); click it again to remove it.
#. Type in **Search apps...** to filter tiles by name.

For the full step-by-step guide, see ``doc/USER_GUIDE.md``
(also available in Ukrainian ``doc/USER_GUIDE.uk.md`` and Polish
``doc/USER_GUIDE.pl.md``).

Known limitations
=================

* Tiles show icon, name and star only; no live counters or badges.
* Favorites follow the app menu sequence; no manual reordering.
* No company-wide default home screen; it is set per user.
* If an administrator changes a user's Home Action directly, the **Home
  Screen** selection is not resynchronised.
* Favorites for apps the user can no longer access are hidden, not deleted.

See ``doc/USER_GUIDE.md`` section "Limitations" for the full list.
