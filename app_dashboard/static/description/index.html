Apps Dashboard

A personal "My Apps" home screen with favorite apps and quick search

Apps Dashboard adds a My Apps screen that shows every Odoo app you can already open as a large square tile with its icon and name. Pin the apps you use most with a star so they always come first, find any app by typing part of its name, and optionally make the dashboard the first screen you see after login. The dashboard follows the native app menu's access rules exactly, so it never shows or grants anything a user could not already open.

Key Features

App tiles and favorites

  • One tile per top-level app the user can see in the native app menu (same group and action access check)
  • Star toggle in each tile's corner pins the app to a Favorites section above All Apps
  • Favorites are personal, stored on the user (favorite_app_menu_ids), and the server refuses apps the user may not open
  • Apps a user loses access to are hidden silently and reappear if access is restored

Search and home screen

  • Search apps... box filters tiles by name as you type
  • Clicking a tile opens the app exactly like the native app menu
  • Home Screen option in My Preferences: Default Menu or Apps Dashboard
  • An administrator-assigned Home Action is never overwritten by choosing Default Menu

How it works

After installation, internal users find a new My Apps entry first in the main app menu (also reachable at /odoo/my-apps). The dashboard lists every app they can open; clicking the star on Project, for example, moves it into Favorites at the top. To start every session on the dashboard, a user opens the avatar menu, chooses My Preferences, sets Home Screen to Apps Dashboard and saves; the change applies at the next login or reload. No new models, security groups or configuration screens are added.
