Employee Custody Management

Know who has the company laptop — and when it is coming back

Register every piece of company property you hand to an employee, run each handover through a request and approval workflow, and let Odoo chase the overdue returns for you. Everything lives inside the Employees app, next to the people it concerns — no separate asset module to learn, no spreadsheet to reconcile.

Key Features

A real register, not a text field

Each item gets its own record with a photo, a description, the owning company and an optional link to a product. A kanban board shows at a glance what is available and who is holding the rest.

Request, approve, return

Requests move through Draft → Waiting Approval → Approved → Returned, with Refused as the terminal branch. Every request gets a sequence reference such as CUST/00001.

One holder at a time — really

The rule is enforced inside the approval method and backed by a partial unique database index, so an import, an RPC call or two officers clicking at the same moment all hit the same guard.

Extensions without losing the original promise

The holder proposes a later date; it is stored separately until an officer approves it. Refusing an extension records its own reason and restores the original return date.

Automatic overdue chasing

A scheduled action runs every day at 05:00, finds every approved request due within a day, and emails the holder a reminder containing a direct link to the record. The same template powers the manual Send Reminder button.

A handover document you can sign

A one-page QWeb PDF on Odoo's standard external layout: your logo and address, the holder's details, the item, the undertaking text and two signature lines. Printable from the form or from a list selection.

Access rights that hold up

Employees see and create only their own requests, enforced by a record rule. The approve, refuse and return actions raise an access error in Python for anyone outside the HR Officer group — the buttons are not merely hidden. Multi-company record rules apply to both models.

Reporting where you expect it

A pivot over the requests themselves — group by item, employee, status or month — plus two smart buttons on every employee form.

How it works

  1. Register the items. Go to Employees → Custody → Items and add a record for each laptop, phone, toolkit or access card, with a photo and a description.
  2. File a request. Under Employees → Custody → Custody Requests, pick the employee, the item, a reason and a promised return date, then click Send for Approval.
  3. Approve or refuse. An HR Officer approves, or refuses with a reason. Approving marks the item as held; the kanban card flips from green to amber.
  4. Print the handover document and have the employee sign it.
  5. Let Odoo chase. If the return date passes, the row turns red and the daily reminder starts going out to the holder.
  6. Close the loop. Click Returned. The actual return date is stamped alongside the promised one, and the item becomes available again.
