Sales reps request product samples for customers. Sales managers approve them,
or reject them with a required reason, and mark approved samples as sent.
Marking a request as sent schedules a "Follow up on sample request" to-do for
the rep, due 14 days after the Sent Date. The rep logs the outcome (Ordered,
Still Thinking or Not Interested) and can link the resulting sales order. Pivot
and graph reports show the sample-to-order conversion rate per sales rep.

Installation
============

To install this module, you need to:

#. Copy the ``sample_request`` folder into your Odoo addons path. It depends on
   ``mail``, ``product`` and ``sale``.
#. Update the apps list (Apps → Update Apps List).
#. Search for "Product Sample Requests" and click Install.

Configuration
=============

The module has no settings page. The only setup is user access:

#. Go to Settings → Users & Companies → Users and open a user.
#. Set **Sample Request** to **User** (sales reps) or **Manager** (people who
   approve and ship samples). ``Sample Request / User`` also gives
   ``Sales / User: Own Documents Only``.
#. The administrator gets ``Sample Request / Manager`` at install time.

Usage
=====

#. Go to Sample Requests → My Requests and click **New**.
#. Select the **Customer**, optionally a **Reason**, and add at least one line
   in the **Products** tab. Then click **Submit**.
#. A manager opens Sample Requests → Approvals and clicks **Approve** or
   **Reject** (the reject dialog requires a reason).
#. After shipping, the manager clicks **Mark as Sent**. The Sent Date is set
   and a follow-up to-do is scheduled for the rep 14 days later.
#. The rep clicks **Log Outcome** and chooses Ordered, Still Thinking or Not
   Interested. For Ordered, the rep can optionally link a Sales Order.
#. Open Sample Requests → Reporting to see Count, Converted and Conversion
   Rate (%) by Sales Rep and Status. The Reporting menu turns on the
   "Sent or Followed Up" filter by default.

For the full step-by-step guide, see ``doc/USER_GUIDE.md``. Translated guides
are in ``doc/USER_GUIDE.uk.md``, ``doc/USER_GUIDE.pl.md`` and
``doc/USER_GUIDE.de.md``.

Known limitations
=================

* No Company field or multi-company record rule. Managers see requests from
  all companies.
* Conversion Rate (%) is meaningful only with the "Sent or Followed Up" filter
  active.
* The linked sales order is not checked against the sampled products or
  amounts, and can only be chosen among the customer's own orders and those of
  its contacts.
* No stock moves or delivery orders are created when samples are marked as
  sent.
* The 14-day follow-up delay is fixed. No second reminder is scheduled for
  "Still Thinking".

See ``doc/USER_GUIDE.md`` section "Limitations" for the full list.
