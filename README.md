# OdoMate — Example Modules

Real Odoo modules generated by [OdoMate](https://www.odomate.pro) — an AI-driven Odoo module
generator that turns business specifications into OCA-aligned Odoo 20 modules with tests,
a live demo, and a downloadable zip.

Every module in the [example modules](#example-modules) table was generated from a written
business specification by the OdoMate team, security-reviewed by a human, and published
unedited apart from publication metadata (store banner reference).
Each module folder contains a `SPEC.md` with the original business specification it was
generated from — so you can judge the input against the output yourself.

The repository also hosts [OdoMate tools](#odomate-tools) — first-party modules we wrote by
hand rather than generated. They are clearly separated below, so nothing here is mistaken
for generator output.

## Repository structure

This repository follows the standard Odoo community convention (the same one OCA and the
Odoo Apps Store use):

- **Branches are named after Odoo series** — you are on `20.0`.
- **Each top-level directory is one installable module** in standard Odoo layout
  (`__manifest__.py`, `models/`, `views/`, `security/`, `tests/`, …).
- **`SPEC.md` inside each module** documents the business specification the module was
  generated from.

## Installing a module

Clone the branch matching your Odoo version and copy the module folder into your addons
path, or download a folder directly:

```bash
git clone --branch 20.0 https://github.com/OdoMate-Org/example-modules.git
cp -r example-modules/<module_name> /path/to/your/addons/
```

Then update the apps list in Odoo and install as usual. Modules target **Odoo 20
Community edition**.

## What these examples are (and aren't)

- They are **real output** — generated from the spec shown in each `SPEC.md`, with the
  generated tests included.
- They pass their automated test suites and install cleanly on Odoo 20 Community.
- They are **not** a substitute for your own review: OdoMate's own guidance is that a human
  reviews generated code before production deployment. These modules went through exactly
  that review.
- None of them contain customer data or beta-user work — all showcase modules are
  team-authored specifications.
