Accounting Daily Reports

Day Book, Cash Book and Bank Book — printable, read-only, multi-company

Three daily accounting books for Odoo 19 Community. The Day Book recaps every journal item of the period day by day. The Cash Book and Bank Book show liquidity movements per account, with an optional opening balance and a true per-account running balance. All three print to PDF and never write a single record, so they stay safe behind lock dates and work for a read-only accountant.

Key features

  • Day Book — one block per calendar day, with per-day debit, credit and difference totals. Empty days produce no block.
  • Cash Book — one block per account over the cash journals, ordered by account code.
  • Bank Book — the same layout over the bank and credit journals.
  • Opening balance — an optional Opening Balance row per account, computed with the same fiscal-year-correct rule as the General Ledger.
  • True running balance — each row carries the previous row's balance plus its own debit minus credit, never the opening repeated.
  • Smart account resolution — journal default, suspense and outstanding payment accounts plus the liquidity accounts actually touched, so a journal without a default account still prints.
  • Multi-currency — every figure in company currency, with an optional column showing each item's own amount.
  • Multi-company — one company per printout, enforced in validation and in every domain.

How it works

  1. Open Accounting → Reporting → Audit Reports and pick Day Book, Cash Book or Bank Book.
  2. Choose Entries (posted only, or all), set the Start Date and End Date, and optionally narrow the Journals.
  3. On the Cash Book and Bank Book, pick Sort by, Display Accounts, and tick Include Opening Balance or With Currency as needed.
  4. Click Print. The PDF opens in the landscape format shared with the other audit reports.

The books read through the Odoo ORM only — no raw SQL, no sudo(), and no field added to any standard model. Access is limited to the Accounting Administrator, full accounting and read-only accounting groups; the module creates no new security group.

Documentation

The full user guide, including a worked numerical example of the opening, running and closing balances, is shipped in doc/USER_GUIDE.md. Translated guides are available in Ukrainian, Polish, German, Spanish, French and Brazilian Portuguese, and the interface itself ships translations for the same six languages.

Requires Accounting Audit Reports (odomate_account_ledger_reports), whose filter dialog, page header and paper format these reports reuse.
