Time Off Requests by Email

One published address. Ordinary Time Off requests. No guessing.

Employees write a plain email with the first and last day of their absence. Odoo turns it into a normal hr.leave request for the person who sent it — same approval flow, same calendar, same reporting. When a message cannot be resolved to an employee, a date or a configured Time Off type, it is refused, recorded, and answered with the accepted date formats. The mail gateway is never allowed to fail on a bad message.

Key Features

One shipped alias

A single mail.alias pointing at hr.leave, restricted to authenticated employees. Publish the address exactly as the settings screen shows it.

Sender resolution that makes sense

Matched against the user's login, the user's email, and the employee's work_email for employees with no user account. In a multi-company database, the employee in the sender's own company wins.

Two date formats, clearly documented

YYYY-MM-DD and DD/MM/YYYY. First date is the first day off, second is the last. A single date requests one day.

A log that answers "what happened to my email?"

Time Off → Reporting → Email Requests lists one read-only row per message, green when a request was created and red when it was refused, with the reason and a link to the request.

An explanation back to the sender

On refusal the sender receives a reply naming the reason and restating both accepted date formats with worked examples — so they can retry without asking anyone.

The missing alias domain, made visible

A fresh database has no mail.alias.domain, so an alias receives nothing. The settings screen says so plainly instead of showing an address that cannot work.

How it works

  1. Set an alias domain under Settings → General Settings → Discuss → Alias Domain and point an incoming mail server or catch-all at Odoo.
  2. Under Settings → Employees → Time Off Requests by Email, switch Requests by Email on and choose the Time Off Type for Email Requests. The feature ships off.
  3. Publish the address shown in Time Off Email Address, for example timeoff-request@ourcompany.com.
  4. An employee writes: "Hi, I'd like 2026-03-09 to 2026-03-13 off." A Time Off request for 9–13 March appears in To Approve.
  5. Time Off officers follow every message — created or refused — under Time Off → Reporting → Email Requests.
