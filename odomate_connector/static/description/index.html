Let OdoMate build modules that fit your actual Odoo

This module exports a redacted structural snapshot of your database as a human-readable odomate_context.json file. OdoMate uses it to generate modules that match your real environment — your installed apps, your customizations, your settings — and to test them against a replica of it.

The export runs entirely inside your own Odoo. This module makes no network calls, stores nothing, and adds no third-party Python dependencies. You download a file and decide what to do with it.

Structural context, never your business records

Included

  • Installed modules, classified core / Enterprise / OCA / third-party / custom, with the manifest website and licence
  • Models and fields, including Studio and x_ customizations
  • Views you have customized or inherited
  • Configuration toggles and allowlisted system parameters
  • Security groups, with a user count each
  • Automated-action names and their models
  • Per-model record counts

Never included

  • Business records of any kind
  • Partner, employee or user data — no names, no emails
  • Credentials, API keys or tokens
  • Secret system parameters
  • The raw database UUID (a SHA-256 hash only)
  • Automated-action code bodies

How the redaction works

  1. Allowlist first. System parameters are only considered if explicitly listed — everything else never leaves.
  2. Pattern second. Any key or value matching key | secret | token | password | api | dkim | private is dropped, including allowlisted ones.
  3. Only boolean and selection settings are read. Odoo core stores real secrets in text settings fields, so reading only booleans and selections excludes that entire class by design.
  4. Groups carry a count, never a membership list.

How to use it

  1. Install the module.
  2. Open Settings › Technical › Export OdoMate Context (requires the Settings administration group).
  3. Press Generate snapshot. You get a summary of what was collected and a download link.
  4. Review the JSON — it is pretty-printed and meant to be read — then upload it in your OdoMate workspace.

Auditable by design. The source is public, the output is plain JSON, and all decisions about what leaves your database live in a single dependency-free file (snapshot_lib.py) so it can be reviewed on its own.
