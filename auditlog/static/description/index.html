Audit Log

Field-level audit trail: who changed what, when, and what it was before

Audit Log records creations, modifications, deletions, reads and exports on the Odoo models you choose. Every audited operation produces a log with the user, date, record and HTTP request, plus one line per changed field with its old and new value in readable form. Administrators, auditors and compliance officers get a searchable history without touching any business module.

Key Features

Flexible audit rules

  • One rule per model (auditlog.rule) with Draft / Confirmed workflow
  • Log Creates, Writes, Deletes, Reads and Exports individually
  • Full log (before/after diff of all stored fields) or Fast log (only submitted values)
  • Users to Exclude and Fields to Exclude per rule
  • Capture Record: snapshot of a record's values when it is deleted
  • On Logging Failure: block the operation or skip the log
  • Configuration read live at every operation, no restart needed

Readable, isolated history

  • Old/new values shown as record names for relational fields, "(DELETED)" for missing ones
  • "View logs" action on the audited record's form
  • Export logs with an Exported Records smart button
  • Flat Log Lines view to search any field change
  • User sessions (SHA-256 fingerprint) and HTTP requests linked to each log
  • Multi-company: logs carry the record's company and follow the user's allowed companies
  • Optional auto-vacuum scheduled action (180-day retention, ships inactive) plus a Delete Old Logs dialog for on-demand purges
  • Logs smart button on each rule opening its model's logs

How it works

With developer mode active, open Settings → Technical → Audit → Rules, create a rule, select a Model such as Contact, choose the operations to log and click Confirm. From then on, renaming the contact "Azure Interior" to "Azure Interior SA" creates one write log whose Fields updated tab shows Name: Azure Interior → Azure Interior SA. Browse everything under Audit → Logs with filters by operation and grouping by user, model, company or date, or open Actions → View logs directly on the contact. Access is split between Auditlog User (read) and Auditlog Manager (full).
