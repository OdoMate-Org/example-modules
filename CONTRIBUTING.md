# Contributing

These are example modules generated by [OdoMate](https://www.odomate.pro) and published as
a showcase of real generator output.

**This repository does not accept pull requests** — changing the code by hand would defeat
the purpose of showing unedited generated output.

- Found a bug or a quality issue in a generated module? Please open an **issue** — that
  feedback is genuinely valuable and flows back into the generator.
- Want a module like one of these for your own use case? [Request beta
  access](https://www.odomate.pro#waitlist) and generate it from your own specification.
